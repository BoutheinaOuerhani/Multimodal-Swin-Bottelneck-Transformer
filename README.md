# Multimodal-Swin-Bottelneck-Transformer
ACMS is an alignment-aware multimodal framework that fuses Hyperspectral and LiDAR data using hierarchical Swin Transformers, bottleneck and gated dual-attention. It effectively overcomes spatial misalignment and modality imbalance to achieve state-of-the-art accuracy in remote sensing land-cover classification.
